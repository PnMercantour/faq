# Création et initialisation du compte d'un nouvel arrivant

## 1. Demande de création de compte

Envoyer un mail à **si@mercantour-parcnational.fr** en précisant :

- **Nom et prénom** de l'agent
- **Fonction** occupée
- Les **ressources nécessaires** :

    - Ordinateur
    - Téléphone
    - Adresse mail `@mercantour-parcnational.fr`
    - Et/ou simple session Windows

Le SI créera le compte et vous enverra par mail un lien contenant le **mot de passe temporaire** de l'agent.

> ⚠️ **Important — à propos du lien reçu :**
>
> - Accessible uniquement depuis le **réseau local** (Ethernet, Wi-Fi `pnm_utilisateurs` ou VPN)
> - Disponible uniquement **à partir de la date d'arrivée** de l'agent
> - **À usage unique** : n'ouvrir le lien qu'au moment de la première connexion

---

## 2. Première connexion

> Effectuer cette étape sur un **ordinateur branché en filaire** au réseau local.

1. Allumer l'ordinateur
2. Sur l'écran de connexion, cliquer sur **Autre utilisateur**
3. Saisir le nom d'utilisateur : 
    
    - Login : `prenom.nom`
    - ou adresse mail : `prenom.nom@mercantour-parcnational.fr`

4. Saisir le mot de passe temporaire récupéré via le lien, puis appuyer sur **Entrée**
5. Choisir un **nouveau mot de passe robuste** lorsque le système le demande
