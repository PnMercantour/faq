# Demande d'accès à Microsoft 365 depuis l'étranger

Par mesure de sécurité, l'accès aux services Microsoft 365 depuis l'étranger est restreint.
Si vous devez vous connecter depuis un pays étranger (mission, congés, etc.), remplissez le formulaire de demande.

[Ouvrir le formulaire de demande :octicons-link-external-24:](https://forms.cloud.microsoft/e/s0CgZPvCmD){ .md-button .md-button--primary target="_blank" rel="noopener" }

Vous devrez vous identifier avec votre compte professionnel Microsoft 365.
